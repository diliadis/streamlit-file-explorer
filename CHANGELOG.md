# Changelog

## 0.1.0 — 2026-10-27

Initial implementation:

- Finder-style Streamlit v2 component with locations, breadcrumbs, search, sorting and pagination.
- File/folder selection, multiple selection, typed results and explicit confirmation.
- Bounded text, table and raster-image previews; isolated theme-aware styling.
- Root-scoped read-only access, symlink rejection, session-local state and cache.
- Local demo, SLURM launcher and deployment documentation.
- Wheels and source distributions with bundled frontend assets; Node-free pip installation.
- Python/frontend tests, cross-platform CI and a Trusted Publishing release workflow.

The public API is new and may change in 0.x releases. Changes will be documented here.
